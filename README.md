## 📌 Project Overview

**CareerConnect** is a responsive landing page created to demonstrate practical frontend web development skills.

The project focuses on creating a professional user interface with responsive layouts, smooth interactions, and an interactive navigation system.

The website is designed to provide a consistent user experience across desktops, tablets, and mobile devices.

## 🎯 Task Requirements

Task 01 required the development of a responsive landing page with an interactive navigation system.

### 📱 Responsive Landing Page

The website adapts to different screen sizes and provides a consistent experience across desktop, tablet, and mobile devices.

### 🧭 Fixed Navigation

The navigation bar remains visible while the user scrolls through the website.

### 🎨 Interactive Navigation

The navigation provides visual feedback when users interact with it.

The navigation styling also changes based on scrolling and hover interactions.
